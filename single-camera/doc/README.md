# Single Camera

Watch your prints with the camera the printer already has, set up in one install.

## What it installs

| Plugin | What it does |
| --- | --- |
| Camera HW Accel | Encodes the video on the printer's video chip, so streaming barely touches the CPU |
| Built-in Camera | Shows the printer's built-in camera as a tile in Fluidd and Mainsail |

Both install together with a single service restart.

## Who it is for

You want one camera and you want it to just work. If you also have a USB camera plugged in, install
"Double Camera" instead; if you want the printer's touchscreen on screen too, install "Watch and
Control".

## After installing

Open Fluidd or Mainsail and the camera tile is there. Nothing to configure under Settings.
